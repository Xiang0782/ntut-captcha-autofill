# 北科入口驗證碼自動填入 (NTUT Captcha)

自動辨識並填入北科大入口網站 (nportal.ntut.edu.tw) 登入頁的驗證碼，並可定時保持登入狀態。

- **不讀取、不儲存帳號密碼**，也不會自動按登入。帳密請自行輸入，或交給瀏覽器的密碼管理員。
- 驗證碼辨識完全在本機（瀏覽器內）執行，圖片不會傳送到任何外部伺服器。
- 從舊版（會存帳密的版本）更新後，先前存過的帳號、密碼會被自動刪除。

## 安裝（載入未封裝的擴充功能）

1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角開啟「開發人員模式 / Developer mode」
3. 點「載入未封裝項目 / Load unpacked」，選擇 **`ntut-ext`** 這個資料夾（不是上一層）

## 使用

打開 https://nportal.ntut.edu.tw/index.do ，驗證碼欄位會自動填好，右下角顯示辨識結果。輸入帳號密碼後按登入即可。

- 按頁面上的「更新驗證碼」換圖時，會自動重新辨識。
- 辨識結果一律為大寫字母；若登入時顯示驗證碼錯誤，頁面換新驗證碼後會再自動填入。
- 不想自動填入時，可在工具列圖示的設定裡關閉。

## 維持登入

入口網站閒置 30 分鐘會自動登出。開啟「維持登入」後（預設開啟），外掛每隔 N 分鐘（預設 10，可設 1–25）請求一次 `myPortal.do`，讓伺服器的閒置計時重新開始。這個功能不需要也不會碰到帳密。

- 有開著入口網站分頁時，請求從該分頁送出；沒有分頁時從背景送出。
- 設定彈窗會顯示「保持連線狀態」與最後檢查時間。
- 若原本已登入、後來被登出（例如電腦睡眠超過 30 分鐘），工具列圖示會出現紅色「!」，需要你自己重新登入。

限制：電腦睡眠或 Chrome 關閉時無法送出請求；從入口網站連進去的其他子系統（例如選課系統）各有自己的登入狀態，不在此功能範圍內。

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `manifest.json` | 擴充功能設定 |
| `content.js` | 在登入頁讀取已顯示的驗證碼圖片、送去辨識、填入欄位 |
| `background.js` | Service Worker，轉送辨識請求、排程維持登入 |
| `offscreen.html/js` | 隱藏頁面，執行 OCR 推論（Service Worker 不能載入 wasm 模組） |
| `popup.html/js` | 設定介面 |
| `model.onnx` | OCR 模型（ddddocr 通用模型） |
| `charset.json` | 模型字元表 |
| `ort/` | onnxruntime-web 執行檔 (wasm) |
